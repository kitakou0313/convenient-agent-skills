# リリース手順（ステージング → 本番）

リリースはステージングで検証してから本番に適用する。ステージングと本番は同じ手順を踏むが、設定ファイルと対象環境が異なる。

1. ステージング用の設定ファイル `config/stg.yaml` を最新のリリース内容に更新する。
2. `deploy.sh --env stg` を実行して、ステージング環境へデプロイする。
3. デプロイ後に `smoke.sh stg` を実行して、ステージング環境のスモークテストを行う。
4. ステージングで問題がなければ、本番用の設定ファイル `config/prod.yaml` を最新のリリース内容に更新する。
5. `deploy.sh --env prod` を実行して、本番環境へデプロイする。
6. デプロイ後に `smoke.sh prod` を実行して、本番環境のスモークテストを行う。
