# 本番DBマイグレーション手順

本手順は、本番データベースのスキーマ変更を安全に適用するためのものである。必ず記載の順序どおりに実施すること。

1. 利用者への影響を避けるため、メンテナンスモードに入る。`touch /var/run/maintenance.flag` を実行する。
2. 万一の巻き戻しに備え、`pg_dump -Fc app_db > backup_0301.dump` でバックアップを取得する。バックアップは必ずマイグレーションの前に取得すること。
3. 適用予定のマイグレーションを確認するため、`./manage.sh migrate --plan` を実行する。想定外のマイグレーションが含まれていないかを目視で確認する。
4. 問題がなければ、`./manage.sh migrate` を実行してマイグレーションを適用する。
5. スキーマ変更をアプリケーションに反映するため、`systemctl restart app.service` でアプリケーションを再起動する。
6. 動作確認が完了したら、`rm /var/run/maintenance.flag` でメンテナンスモードを解除する。
